# 1.4.0 (32) — What's New

Paste each block into App Store Connect and Google Play. Each block is under
Google Play's 500-character limit.

## English (en-US)

- Search your calculation history
- Swiped away a calculation by mistake? Tap Undo to bring it back
- Paste a number from the clipboard with the new paste button or Ctrl/Cmd+V
- New Tips and shortcuts page in Settings
- Themes now apply instantly across the whole calculator
- More accurate results: 0.1 + 0.2 now shows 0.3
- Typing after = starts a new number
- Fewer interruptions while choosing a theme
- Better screen reader support for theme selection
